# Production Research Hub

Built 2026-10-17. One place for the research on how producers and engineers work, effects, mixing, and music theory.

## How to read this
- Each chapter is a folder in `Chapters/`. Each part is under 450 lines, so nothing gets skipped.
- Open a chapter, start at Part 1, and follow the "Next" line at the top of each part.
- `Originals/` holds exact, untouched copies of every source file, in the same folder layout as where they came from.
- `MANIFEST.txt` lists every file, where it came from, and its size.
