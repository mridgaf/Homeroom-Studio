# Homeroom UI job — write-up (paused 2026-11-01)

Built in **Homeroom Studio** (owner's pick over Beat Lab Codex), from
`UI Handoff/Claude Final Package` (mockups 01, 01b, 02, 03). Look and layout only —
every id, button and server call kept. Nothing committed. No beats or sketches rendered.

## Done

### 1. Main page — Beat generator (`tools/beat_machine.py`, the `_PAGE` template)
- Black panels, HOMEROOM / STUDIOS wordmark, HS shield, four colours
  (orange / green / violet / blue) set as CSS variables.
- Sidebar: Beat Making, My Beats (opens Saved Beats), Get Schooled.
- **1 Choose your class**: two tabs (Back of the Class / Legends), round portrait
  placeholders, pick order shown as a number. Collabs work as before.
- **2 Set your parameters**: Key, Number of beats (1–10, up/down), Style (multi-pick of the
  genres), Directions, tempo **flask** (liquid and scale both come from the real tempo range,
  60–200, so they always agree), −/+ buttons, **Loops only** switch.
- **Loops only**: same four colours, roles swap (green leads), and the words change too
  ("Loop mode", "Generate Loops") so colour isn't the only sign.
- Toolbar pop-ups: Pattern Library, Breaks, Saved Beats, Famous Beats (dot when one is picked),
  Reference (small upload).
- Beat cards: small art, title, tags, key | BPM | length, waveform (played part lit),
  **Pass / Fail** (still moves files, never deletes), Sketch, Stems, Open Physics, "…" menu.
- **Elements** panel: tiles for the selected beat's real sounds (from `/stems`), any count,
  scrolls; click a tile → opens Stems at that sound.
- Bottom **now-playing bar**: title, progress, previous / play / next, queue of the list.

### 2. Sketch (`tools/sketch_ui/sketch.js` + `sketch.css`)
- Laid out like mockup 02: Arrangement preset, Section effects (Built in / Genre / Random /
  Re-roll), instruments down the side with "who is who", sections across, coloured cells
  (each instrument keeps one colour pair), cell editor on the right (sits out + effect moves),
  one Echo/reverb amount, Make the sketch, Listen bar (Sketch / Plain loop A/B, sections,
  download). Same `/sketch` recipe as before.

### 3. Physics — Effects page (`sound_engine/static/`)
- First pass: re-skin + "Flask" → "Bus" wording.
- Second pass (owner said rebuild): new `index.html` layout + `physics.js` + `physics.css`.
  Top bar (play, stop, loop, Back to beats, Send back, Sketch, Export) · stems list ·
  selected stem (Level + Pan knobs, M / S, Bus A/B, quick-effect knobs) · one effect's
  settings with a **real EQ curve** (read from the stem's own filters) · effects list with
  on-lights · bottom bar (Load audio, Browse beats, Bus A + B levels, Master dry/wet, Hold,
  Base clean-up, Reset). `science.css` is no longer loaded.
