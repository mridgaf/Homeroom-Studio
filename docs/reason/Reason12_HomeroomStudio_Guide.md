## 🎯 Most Critical (Start Here)

### 1. **Save Remote Templates** — Your Workflow Multiplier
**Why it matters:** You're doing music production. Starting from scratch wastes time.
**How to do it:**
- Create a song with your preferred devices and settings
- Remove all sequencer data (clips) but keep device setups
- Save as a Template Song (File → Song Information → Save as Default Song)
**What you get:** Every new project opens with your ideal setup ready
**Time saved:** 10-30 minutes per session

### 2. **Keyboard Control Setup** — Faster Parameter Tweaking
**Why it matters:** You need to adjust synths and effects quickly while writing
**How to do it:**
- Go to Reason → Settings → Control Surfaces
- Add "Keyboard" or your MIDI keyboard
- Enable "Keyboard Control" on devices
- Map keys to parameters (pitch bend for filter, mod wheel for LFO, etc.)
**What you get:** Hands-on control without touching the mouse
**Pro tip:** Map your most-used knobs to keyboard shortcuts

### 3. **Gamepad Combinator Control** — Live Performance Ready
**Why it matters:** You want tactile control for mixing and live performance
**What you need:**
- PS5 DualSense or Xbox controller
- Universal Controller MIDI v1.0+ (free download)
**Setup:**
1. Install Universal Controller MIDI
2. Bridge to virtual MIDI (Audio MIDI Setup on macOS)
3. Register as Remote surface in Reason
4. Map gamepad sticks to Combinator rotaries
**What you get:** One thumb controls filter, sample start, reverb simultaneously
**Cost:** $0 (if you already have a gamepad)

## 🎹 Essential Templates (Build These)

### 4. **Drum Rack Template**
**Components:** Kong Drum Designer, Redrum, or NN-XT
**Setup:**
- Load your go-to drum samples
- Route individual drums to separate mixer channels
- Add basic compression on drum bus
- Save as template

### 5. **Bass Synth Chain**
**Components:** Europa, Thor, or Monark
**Setup:**
- Your preferred bass patch pre-loaded
- EQ, saturation, compression chain ready
- Sidechain compression routed
- Save as template

### 6. **Vocal Processing Chain**
**Components:** Any vocal synth + effects chain
**Setup:**
- EQ, compression, de-esser, reverb ready
- Input routing pre-configured
- Color-code channels visually

### 7. **Live Performance Rack** (If you gig)
**Components:** Minimal CPU instruments
- Solid bass, lead synth, drum machine
- Combinators for quick patch changes
- External audio input pre-routed
- Low CPU usage setup

## ⚡ Quick Tips & Tricks

### 8. **Color-Code Everything**
- Mixer channels and devices
- Visually group related elements
- Faster navigation when returning to projects

### 9. **Use Combinators Strategically**
- Consolidate rotaries across the rack
- Create macro controls for mixing
- One surface = multiple parameters

### 10. **Hide Unused Devices**
- Put rarely-used tools in collapsed Combinators
- Keep workspace clean
- Quick access when needed

### 11. **Save Projects as Templates, Not Finished Tracks**
- Templates = starting points
- Finished tracks = complete songs
- Don't confuse the two!

### 12. **Name Everything Descriptively**
- "Kick Drum" not "Drum 1"
- "Europa Lead" not "Synth 3"
- "Vocal Reverb Send" not "Channel 5"

## 🔄 Automation & Chains

### 13. **Note and Automation Editing**
**What it is:** Edit recorded automation events after the fact
**How to use:**
- Double-click clip to open in Edit Mode
- Select events to edit or draw
- Manually create events in clips

### 14. **Remote Override Mapping**
**What it is:** Customize default MIDI mappings
**How to use:**
- Right-click parameter
- Pick "Edit Remote Override Mapping"
- Move controller to capture CC and channel
- Save your custom mappings

### 15. **Surface Locking**
**What it is:** Lock a MIDI surface to one device
**When to use:** During performance when you want dedicated control
**How to use:**
- Remote → Settings → Lock Surface
- Select device to lock to
- Unlock when done

## 🎮 Hardware Integration

### 18. **External Control Surfaces**
**What works:** Behringer, Native Instruments, AVID controllers
**Setup:**
- Reason → Settings → Control Surfaces
- Add your device
- Use Standard Remote mapping (usually built-in)
- Override only when needed

### 19. **MIDI Keyboard Integration**
**What you get:** Pitch bend, mod wheel, velocity, aftertouch
**Setup:**
- Enable Keyboard Control on devices
- Map keys to specific parameters
- Test with each device

### 20. **Gamepad Mapping Ideas**
**Left stick:** Rotaries 1 & 2 (filter cutoff, LFO depth)
**Right stick:** Rotaries 3 & 4 (sample windows, modulation)
**Face buttons:** Combinator buttons 1-4 (bypass FX, swap routings)
**Touchpad:** RV7000 size and damp
**D-pad:** Sequencer transport

## ⚠️ Common Pitfalls to Avoid

### 27. **Don't Overload Templates**
- Keep templates focused on one purpose
- Too many devices = slow startup
- Test performance before saving

### 28. **Don't Save Finished Tracks as Templates**
- Templates should be starting points
- Empty sequencer = template
- Full sequencer = project

### 29. **Don't Forget to Name Things**
- "Track 1" is useless
- "Kick Drum" is useful
- Spend 2 minutes naming, save 20 later
