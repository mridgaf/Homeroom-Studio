## How to read the tags
- **[Manual]** = in the Reason 12.7 Operation Manual (strongest).
- **[Web]** = a web source. Each file lists URLs and what kind of source (official article, forum opinion, old). Summaries only, nothing copied.
- **[Guess]** = my idea. Not in a source, not tested.
- NOTHING has been heard in Reason. All settings are starting points.

## Rules I followed
- Reason **12.7** only. Web pages about Reason 13/14 features (Sidechain Tool, Gain Tool, Stereo Tool, Ripley, Track Panel, Rack per Track, RV-9) are marked "not in 12" and a 12.7 substitute is given. Check: those four names don't appear in the 12.7 manual.
- Parameter names follow `device_refs/` (copied from the manual / remote map).
- I skipped a Reason Studios page that read like auto-generated filler with errors (808 bass lines, 2025). Noted in `bass-and-low-end.md`.
- A forum site and one video page blocked automated reading. I did not work around it; those are marked unverified.
