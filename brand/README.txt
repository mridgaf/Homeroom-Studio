HOME ROOM STUDIO — band artwork
================================

Drop the two Back of the Class logo files in THIS folder, named exactly:

    logo-blue.png     the yellow mark on the blue square
    logo-black.png    the black mark on white

The page picks them up the next time you launch it — no code to change.
logo-blue.png is the one that shows in the masthead; logo-black.png is
used where the page needs the mark on a light surface.

Any of .png .jpg .jpeg .webp .gif .svg works. If neither file is here
the page falls back to a plain type mark, so nothing breaks.
