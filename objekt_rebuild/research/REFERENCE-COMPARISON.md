# How to close the remaining audio gap

The user owns Reason 12 but does not own Objekt. Companion's catalog strings cannot serve as an audio reference. The official product page offers a trial: https://www.reasonstudios.com/shop/rack-extension/objekt-modeling-synthesizer/ . Obtaining a valid license or trial and signing in is the first dependency; this project must not fetch packages from Companion's internal endpoints or bypass entitlement. Keep the original and rebuild on separate tracks, and do not replace either's files.

Once the user has an authorized Objekt installation, capture reference output at 48 kHz/32-bit float with all global effects and mixer processing off. Use one note at a time, C2/C3/C4/C5, velocities 32/64/96/127, fixed note lengths 50 ms/500 ms/2 s, and long release tails. Record dry exciter only, each modal stage individually, each Object stage individually, and the same configurations with coupling Off/On/X-Over. Then sweep one control at a time through minimum/center/maximum, holding every other control fixed. Include external impulse and white-noise inputs for frequency-response and nonlinear tests. Retain the exact patch settings, DAW project, MIDI and WAV files beside every result.

Compare onset time, peak/RMS, pitch in cents, decay slope, spectral peaks/notches, stereo correlation and velocity response. First fit independently documented parameters (pulse duration, resonator ratios/decays, delay tuning), then refine nonlinear behavior using held-out notes/velocities. Listen blind to both versions in musical phrases; numerical similarity alone is insufficient. Publish a table for every tested control with measured error and remaining uncertainty. Without reference access, exact algorithms, tapers, factory-patch compatibility and listener-approved parity cannot be asserted.

Functional work that does not require reference access: implement the remaining documented diffuse, exciter EQ, strike position, damping bands, coupling modes, release mute, key modes and tuner interface; make controls automatable and check their effect on audio. See ../vst3/REMAINING-GAPS.md for current details.
