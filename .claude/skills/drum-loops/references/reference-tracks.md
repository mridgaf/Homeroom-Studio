# Reference Tracks & Loudness Targets

Distilled from `research-references-education.md` (raw report in this same directory).
`[folklore]` = practitioner/community consensus, not a published spec — labels don't publish LUFS.

## Mix balance

| Track | Why it's cited | Listen for |
|---|---|---|
| Dr. Dre — Still D.R.E. | Most-recurring hip hop mix reference; cut through SSL desk + Neve pres | Clean balanced vocal, near-perfect mono compatibility, round warm low end |
| Mos Def — Do It Now (ft. Busta) | iZotope's textbook frequency-slotting example | Kick ~60 Hz, snare ~200 Hz, vocal presence ~2 kHz — nothing overlaps |
| Kendrick — King Kunta / HUMBLE. / All The Stars | Modern balance benchmarks (iZotope, eMastered) | Even spectrum, bass-forward but not muddy, drums sitting above the bass |
| Post Malone — rockstar | AMAC's (mix engineer) stated go-to | Two contrasting vocal takes balanced with space and dynamics |
| J. Cole — KOD | Clean modern mixing reference | Undistorted bass, precise transients, everything legible |

## Drum & 808 tone

| Track | Why it's cited | Listen for |
|---|---|---|
| 50 Cent — In Da Club | Recurs constantly as the "tight bass" model | Unusually tight bass; drums take precedence over the 808 |
| Jay Rock/Kendrick/Future — King's Dead | iZotope reference for complex low end | Multiple kick patterns with zero mud; bass "dirty, out front" |
| Travis Scott — SICKO MODE | Modern trap 808 touchstone `[folklore]` | Booming glided 808 across 3 beat switches; Mike Dean low-end saturation |
| Eminem — Darkness | iZotope's translation-trick example | Deliberate bass distortion so the 808 reads on small speakers |
| Uzi "Lo Mein" / Smokepurpp "Nephew" / Moneybagg Yo "Dior" | Gearspace trap-thread staples `[folklore]` | 808 as "the star" — everything else high-passed out of its way |

## Loudness / mastering

No label publishes per-track LUFS; these are the repeatedly-cited practitioner numbers.

- **-8 to -9 LUFS integrated — the current working target for modern hip hop/trap masters.**
  This is what the drum-loops engine defaults to. **Keep it** — it sits inside the most-repeated
  range across independent genre guides and is the right call for a "loud, competitive, club-ready"
  master. `[folklore — practitioner consensus, not a lab spec]`
- **-7 LUFS** — pushed for singles, only if transients still survive.
- **Optional streaming-safe mode: -12 LUFS integrated, ≤ -1 dBTP.** Add this as an *alternate*
  target for users mixing for Spotify/YouTube normalization rather than club playback — don't make
  it the default.
- **-1 dBTP** true-peak ceiling — hold this regardless of integrated target, to avoid inter-sample
  clipping on lossy/streaming playback.
- Historical club/CD masters ran hotter still (-9 to -6 LUFS) — pre-streaming-normalization habit,
  not a current target.

## Free education (well-known, all free)

| Resource | Teaches | Best takeaway |
|---|---|---|
| Berklee Intro to Music Production (Coursera) | DAW-agnostic recording/mixing/synthesis | Gain staging + signal chain literacy |
| BerkleeX Intro to Music Theory (edX) | Scales, intervals, chords, ear training | Minor scales + chord function → better loops |
| Open Yale MUSI 112 (Craig Wright) | How music is built; active listening; form | Hearing song architecture (intro/verse/hook) |
| MIT OCW Music & Technology | Recording history, algorithmic/generative music | Sampling's lineage: musique concrète → hip hop |
| musictheory.net | Interactive theory lessons + ear trainers | Daily interval ear-training drills |
| Open Music Theory v2 (free textbook) | Full theory sequence + pop/jazz units | Pop-harmony chapters = hip hop's actual loops |
| In The Mix (YouTube) | Beginner mixing/mastering | Clearest EQ/compression explainers |
| Produce Like A Pro (YouTube) | Full pro mix breakdowns | Watching a real mix start-to-finish |
| Pensado's Place (YouTube) | Interviews with hit-record mixers | Real engineers explaining rap/R&B vocal chains |
