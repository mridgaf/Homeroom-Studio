Gated Snare (Phil Collins style)

Accuracy B · theoretical

  1. Load a Redrum and pick a big acoustic snare.
  2. Add a Gate after it. Short hold, fast release.
  3. Send the snare into a large Reverb.
  4. Put the Gate on the reverb return so the tail chops off.
  5. Nudge the reverb size until it slams and stops.
